# Contacto

## Ponte en Contacto

¡Nos encantaría saber de ti! Aquí están las mejores formas de contactarnos:

### Issues de GitHub

La forma principal de ponerse en contacto es a través de [GitHub Issues][1]. Este es el mejor lugar para:

- Reportar errores o problemas
- Sugerir nuevas características o mejoras
- Hacer preguntas sobre el proyecto
- Discutir posibles contribuciones

### Contribuir

Si te gustaría contribuir al proyecto:

- Haz un fork del repositorio en [GitHub][2]
- Envía un pull request con tus cambios
- Sigue las [guías de contribución][3] descritas en el README

- **Sitio Web**: [httpstatuscodes.org][4]
