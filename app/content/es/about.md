# Acerca de

httpstatuscodes.org es una base de datos fácil de consultar de Códigos de Estado HTTP con sus definiciones y referencias de código útiles, cada código accesible en `httpstatuscodes.org/code`. Se incluyen todos los códigos estándar, así como algunos códigos no estándar que tienen presencia significativa en la web.

## Historia del Proyecto

Este proyecto originalmente se conocía como [httpstatus.es][1] pero migró a [httpstatuses.com][2] en noviembre de 2015 por razones de SEO.

**Estado Actual del Proyecto Original:**
El httpstatuses.com original ya no está disponible como sitio de referencia - ahora redirige a un sitio web comercial. El repositorio original ha sido transferido a un nuevo propietario pero permanece inactivo desde noviembre de 2016.

**Este Proyecto:**
Este es un proyecto de hobby reconstruido desde cero con tecnologías modernas (Flask y Tailwind CSS) con la intención de revivir y mantener la referencia de códigos de estado HTTP que estaba disponible anteriormente. El objetivo es proporcionar el mismo recurso valioso que ofrecía el proyecto original, pero con tecnología actualizada y mantenimiento activo.

## Stack Tecnológico

Este proyecto está construido con:

- **Flask** - Framework web de Python
- **Tailwind CSS** - Framework CSS utility-first
- **Markdown** - Formato de contenido para códigos de estado

El proyecto se mantiene en [github.com/Diavolo/httpstatuscodes][3].
